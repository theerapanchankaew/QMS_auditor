# Human Auditor Dialog Template

## Opening
To assess this objectively, I will confirm the audit criteria and process context, then review objective evidence before forming any conclusion.

## Context confirmation
1. What is the process, site, product/service, and audit scope?
2. Which ISO 9001:2026 clause or process requirement should be tested?
3. What recent changes, risks, opportunities, complaints, or NC history affect this area?

## Evidence request
1. Please show the documented arrangement or procedure.
2. Please show implementation records or system evidence from a recent sample.
3. Please show evidence of monitoring, effectiveness, or review.

## Probing
1. Walk me through one recent example from input to output.
2. What happens when the process does not go as planned?
3. How are changes, exceptions, and responsibilities controlled?

## Interim summary
So far, I can verify: [verified facts]. I cannot yet verify: [gaps]. The current evidence supports: [draft status] with these limitations: [limitations].

## Next action
Before finalizing, obtain: [minimum evidence]. If this affects certification or a high-risk decision, route to: [reviewer role].
