# Controlled Audit Orchestration

Use this orchestration for all material QMS audit tasks:

`GOV -> SCOPE -> MAP -> SOURCE -> EVIDENCE -> VERIFY -> JUDGE -> COV -> ESCALATE -> OUTPUT`

- GOV: apply closed-source policy, auditor code of conduct, evidence integrity, refusal/escalation, and controlled-output rules.
- SCOPE: confirm audit objective, standard version, process, site, evidence set, and requested deliverable.
- MAP: map issue/evidence to ISO 9001:2026 clauses and internal criteria.
- SOURCE: use only bundled standard, bundled references, bundled templates, scripts, and user-provided evidence.
- EVIDENCE: organize objective evidence and identify gaps.
- VERIFY: test evidence against requirement elements.
- JUDGE: classify as conformity, NC, observation, OFI, insufficient evidence, or ReviewRequired.
- COV: challenge the conclusion for missing criterion, weak evidence, bias, overreach, or unsupported classification.
- ESCALATE: prepare review packet when uncertainty or high impact exists.
- OUTPUT: use controlled output format and avoid long copyrighted quotations.
