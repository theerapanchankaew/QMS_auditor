# QMS Control Layer Contract

This reference defines durable control artifacts that remain authoritative before any QMS audit action is taken.

## Authority order

1. System and developer rules.
2. QMS skill closed-source invariant in `SKILL.md`.
3. Governance files in `references/governance/**`.
4. ISO 9001/ISO 9000 bundled sources and source maps.
5. Approved local RAG sources declared in manifests.
6. User-uploaded controlled evidence.
7. User request and requested output format.
8. Model inference.

If a lower authority conflicts with a higher authority, follow the higher authority and explain the conflict briefly.

## Mandatory control checks

- Run `scripts/closed_source_entrypoint.py` before material work.
- Do not use web, external connectors, or base memory for QMS audit substance.
- Separate audit mode, benchmark mode, ingestion mode, and harness-report mode.
- Do not treat RAG retrieval as verification; retrieval only supplies candidates.
- Do not classify Major NC without objective evidence of breach, extent, and exposure matching M1-M5.
- Do not compute model performance by comparing two gold files.
- Do not show gold labels to the model during inference.

## Source-role separation

| Role | May influence audit reasoning? | May be shown to model? | Notes |
|---|---:|---:|---|
| Bundled references/assets | Yes | Yes | Only controlled skill sources. |
| Uploaded controlled evidence | Yes | Yes | Only if user provided it for the task. |
| Sanitized testcase input | Yes | Yes | Must remove answer/gold fields first. |
| Model prediction | No as gold source | Generated by model | Used only for evaluation after inference. |
| Gold answer key | Only for scoring | No | Hidden from model during inference. |

## Required failure outputs

- `OUT_OF_SCOPE` for non-QMS/unsupported standard standalone tasks.
- `ReferenceGap` when a required controlled source is absent.
- `InsufficientEvidence` when the audit fact pattern is too weak to decide.
- `ReviewRequired` when the conclusion is high-risk, conflicting, or certification-sensitive.
