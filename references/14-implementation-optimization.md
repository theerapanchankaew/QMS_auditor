# Implementation Optimization

## Purpose
Preserve TurboQuant, codebook, and inference configuration concepts as implementation optimization knowledge.

## Boundary Rule
Optimization improves delivery efficiency. It must not modify audit criteria, evidence sufficiency, clause interpretation, verdict logic, NC classification, or escalation thresholds.

## Appropriate Uses
- Choose efficient runtime profile.
- Reduce cost or latency.
- Support constrained deployment.
- Compare profile or codebook choices after audit logic is already defined.

## Inappropriate Uses
- Overriding ISO requirements.
- Lowering evidence expectations.
- Changing NC severity.
- Avoiding human review when review is required.

## Relationship to G4/B4/L4
Reasoning profiles may guide retrieval and verification style. Implementation profiles may optimize execution. Keep these concepts separate unless explicitly designing deployment infrastructure.
