Use this file when the user asks how the QMS auditor skill is governed, made repeatable, measured, hardened, or reverse-engineered. This HarnessCard reports the extra-model harness layer that turns the language model into a controlled QMS audit assistant.

| Field | QMS auditor disclosure |

| Governance layer | Closed-source invariant, no web/external connectors, evidence integrity, auditor code of conduct, refusal/escalation rules, controlled output rules. |
