# QMS NC Severity Calibration Guide — ISO 9001:2026 v1.0
> **Purpose:** Provide clause-specific Major/Minor calibration anchors for L10–L11 of the Layered QMS Audit Cognition Engine.
> **Usage:** After L9 exposure analysis names an M-trigger or confirms none, cross-check against this table to validate or refine the severity decision.
> **Related:** `references/26-layered-audit-cognition.md` L10; `references/10-nc-classification-rules.md`

---

## QMS Major Triggers (M1–M5)

| Code | Trigger | Typical evidence |
|---|---|---|
| **M1** | Product/service conformity exposure — control failure lets nonconforming output reach or threaten the customer | Released product, failed sample, uncontrolled production |
| **M2** | Customer / statutory / regulatory / contract breach — obligation actually or imminently violated | PO term not met, regulator notification, contract deviation |
| **M3** | Release / delivery without required verification or with uncontrolled nonconforming output | Shipment record before acceptance signature, 8.6/8.7 record gap |
| **M4** | Entire required system element completely absent | No internal audit programme, no CA process, no 8.3 design control (when applicable), no supplier evaluation |
| **M5** | Systemic or repeated failure — same NC recurred after verified CA closure, or widespread across sites/processes | Second identical NC, multi-site failure, CA effectiveness record absent after re-audit |

**Hard rule:** Major requires a named, proven M-trigger. If no M-trigger can be named → Minor or ReviewRequired.

---

## QMS Minor Anchors (D1–D4)

| Code | Anchor | Typical pattern |
|---|---|---|
| **D1** | Documentation / record gap without conformity exposure | Missing record field, incomplete register, one signature absent |
| **D2** | Weak or incomplete process — process exists but has gaps | Procedure exists, partial implementation, some samples missing |
| **D3** | Leadership / awareness / competence weakness without demonstrated system failure | Training not recorded, quality culture not deployed to one function |
| **D4** | Isolated single lapse without recurrence or pattern | One non-conforming sample in a batch that otherwise complies |

## Clause 4.1 — Context of the Organization

| Situation | Severity |
|---|---|
| No context analysis process at all | **Major M4** |
| Context not reviewed when significant changes occurred (QMS ineffectiveness risk) | **Major M5** |
| External/internal issues listed but not linked to QMS or quality culture considerations | Minor D2 |
| Climate change / quality culture not considered but other elements present | Minor D2 or OFI depending on evidence |

---

## Clause 4.2 — Interested Parties

| Situation | Severity |
|---|---|
| No interested party determination at all | **Major M4** |
| Legal/regulatory party not included | Minor D2 → **Major M2** if breach demonstrated |
| Parties listed but requirements not mapped to QMS | Minor D2 |

---

## Clause 5.1 — Leadership and Commitment

| Situation | Severity |
|---|---|
| Policy exists but zero evidence of deployment or integration | InsufficientEvidence or Minor D2 |
| Management review not conducted | **Major M4** |
| Quality culture / ethical behaviour not promoted (2026 theme) | OFI if no impact; Minor D3 if pattern shown |

---

## Clause 6.1 — Risks and Opportunities

| Situation | Severity |
|---|---|
| No risk/opportunity planning process at all | **Major M4** |
| Risks identified but no actions planned or integrated | Minor D2 → **Major M1** if risk materialised |
| Opportunities not identified but risks addressed | OFI |

---

## Clause 6.3 — Planning of Changes

| Situation | Severity |
|---|---|
| Change implemented without any planning control | **Major M1/M3** if change affected product/service conformity |
| Change planned but without formal review of consequences | Minor D2 |
| Post-change review not documented | Minor D1 |

---

## Clause 7.1.5 — Monitoring and Measuring Resources

| Situation | Severity |
|---|---|
| Measurement equipment used for release decisions not calibrated | **Major M3** if product released based on uncalibrated result |
| Calibration overdue but equipment not yet used for critical decisions | Minor D2 |
| Calibration record missing for traceable equipment | Minor D1 |
| Calibration records show out-of-tolerance and no impact assessment | **Major M1** |

---

## Clause 7.2 — Competence

| Situation | Severity |
|---|---|
| No competence determination for quality-critical processes | Minor D2 → **Major M1** if product conformity uncontrolled as result |
| Competence gap identified; no action taken | Minor D2 |
| Training completed but no effectiveness evaluation | Minor D1 |
| Person performing critical process with no qualification evidence | **Major M1** if direct product risk |

---

## Clause 7.5 — Documented Information

| Situation | Severity |
|---|---|
| Entire document control process absent | **Major M4** |
| One required record missing or unsigned | Minor D1 |
| Obsolete documents available at point of use | Minor D2 |
| Critical production parameter controlled by undocumented verbal instruction only | **Major M1** |

---

## Clause 8.3 — Design and Development

| Situation | Severity |
|---|---|
| Design/development applicable but entire process absent | **Major M4** |
| Design process exists but one phase (e.g. verification) absent | Minor D2 → **Major M3** if unverified design released |
| Design changes not controlled | **Major M1/M3** |
| Design outputs not reviewed before release | **Major M3** |

---

## Clause 8.4 — Control of Externally Provided Processes/Products/Services

| Situation | Severity |
|---|---|
| No supplier evaluation or control for any supplier | **Major M4** |
| No evaluation/control for critical supplier (affects conformity) | **Major M1 or M4** |
| Supplier evaluation exists but one critical supplier missed | Minor D2 → **Major M1** if product impact demonstrated |
| Communication of requirements to supplier absent | Minor D2 |

---

## Clause 8.5 — Production and Service Provision

| Situation | Severity |
|---|---|
| Process control absent for critical production/service process | **Major M1** |
| Controls present but one sub-step weak | Minor D2 |
| Property of customer/external provider not identified or protected | Minor D2 → **Major M2** if contract breach |
| Post-delivery activity required by customer not performed | **Major M2** |

---

## Clause 8.6 — Release of Products and Services

| Situation | Severity |
|---|---|
| Product released before acceptance evidence exists | **Major M3** |
| Release authorization not traceable to authorized person | **Major M3** |
| Acceptance criteria not defined | **Major M4** |
| One signature field missing in otherwise complete record | Minor D1 |
| Sampling plan applied but not documented | Minor D2 |

---

## Clause 8.7 — Control of Nonconforming Outputs

| Situation | Severity |
|---|---|
| Nonconforming output released to customer without authorization | **Major M3** |
| No process for controlling nonconforming outputs | **Major M4** |
| NC output identified but disposition not recorded | Minor D1 |
| Concession issued without customer authorization when required | **Major M2** |
| NC process exists but isolated record incomplete | Minor D1 |

## Clause 9.1 — Monitoring, Measurement, Analysis and Evaluation

| Situation | Severity |
|---|---|
| No monitoring/measurement process at all | **Major M4** |
| Monitoring exists but weak/incomplete for key processes | Minor D2 |
| Customer satisfaction not monitored | Minor D2 |
| Results not analyzed or not used for improvement | OFI |

---

## Clause 9.2 — Internal Audit

| Situation | Severity |
|---|---|
| No internal audit programme at all | **Major M4** |
| Programme exists; high-risk areas excluded | Minor D2 → **Major M5** if exclusion is systematic and recurring |
| Audits not completed on schedule (one cycle missed) | Minor D2 |
| Auditor objectivity not ensured (self-audit) | Minor D2 |
| Previous audit NCs excluded from follow-up | **Major M5** |

---

## Clause 9.3 — Management Review

| Situation | Severity |
|---|---|
| No management review conducted | **Major M4** |
| Review conducted but required inputs missing | Minor D2 |
| Review conclusions not recorded | Minor D1 |
| Outputs do not include resource decisions | Minor D2 |

---

## Clause 10.2 — Nonconformity and Corrective Action

| Situation | Severity |
|---|---|
| No CA process at all | **Major M4** |
| Repeated NC after CA closed as effective | **Major M5** |
| Correction only, no RCA or CA | Minor D2 |
| CA plan but no effectiveness review | Minor D2 |
| Isolated minor CA with incomplete documentation | Minor D1 |

---

## Clause 10.3 — Continual Improvement

| Situation | Severity |
|---|---|
| No improvement activity at all and QMS stagnating | OFI (unless contributing to systemic failure) |
| Improvement not systematic but requirements met | OFI |
| Improvement opportunities identified but never actioned | Minor D3 |
